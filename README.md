# 📁 نظام الأرشفة الذكي  
نظام ذكي لإدارة الوثائق، استخراج النصوص، تصنيفها، وتخزينها داخل إضابير منظمة باستخدام تقنيات OCR و NLP.

---

## 🎯 فكرة المشروع
يهدف المشروع إلى:
- رفع الوثائق بصيغ مختلفة (PDF – صور)
- استخراج النص باستخدام OCR
- إنشاء تمثيل عددي (Vector Embedding)
- تصنيف الوثيقة تلقائيًا حسب المجال
- تخزين الوثائق داخل إضابير منظمة
- عرض تفاصيل الوثيقة داخل لوحة تحكم احترافية

---

## 🧠 التقنيات المستخدمة
- Python / Django  
- CAMeLBERT Embeddings  
- Projection Head  
- Machine Learning Classification  
- SQLite  
- HTML / CSS / Bootstrap
